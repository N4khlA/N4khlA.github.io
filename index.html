F‑01
Impact · High Offensive / Web Status · Shipped

Race Condition Exploiter

A full-stack TOCTOU lab. It is a deliberately vulnerable shop with five real race bugs: double-spend wallet transfers, coupon reuse, overselling stock, duplicate signups and password-reset token reuse. Each one can be exploited, detected and fixed from the same live dashboard.

Technique

  • Four concurrency strategies: asyncio, barrier-synced threads, raw TCP sockets, HTTP/2 multiplexing
  • Microsecond-level request staggering to find the race window

Detection & fix

  • PostgreSQL invariant triggers streamed via LISTEN/NOTIFY, burst fingerprinting
  • CAS, row locks, serializable and Redis locks, each benchmarked for exploit rate against latency

F‑02
Impact · High Defensive / ML Status · Shipped

ML Network Intrusion Detection

Detects DoS, scans, exploits, fuzzing and botnet traffic in UNSW-NB15 flow records. Predictions are served through a REST API and monitored on a live dashboard, and the retraining pipeline refuses to replace the current model with a worse one.

Method

  • Random Forest (per flow) compared with a bidirectional LSTM (per window)
  • McNemar significance test, which honestly showed the gap was not significant (p = 0.058)

Rigour

  • Leakage scan, per-attack-family recall, documented weak spots
  • Seeded, reproducible pipeline with 49 tests

F‑03
Impact · High AppSec / Mobile Status · Shipped

masa: Mobile App Security Analyzer

A static scanner for Android APKs and iOS IPAs that maps findings to the OWASP Mobile Top 10 (2023). It uses only the Python standard library, so every binary format parser is hand-written.

Under the hood

  • Parsers for binary AXML, bplist, DEX string tables, ELF and Mach-O
  • Binary hardening checks: PIE, RELRO, executable stack, unsafe libc calls

Coverage

  • Secrets, TrustAll managers, ATS bypasses, weak crypto, insecure storage
  • Credits positive controls (Keystore, Keychain, pinning); HTML/MD/JSON reports
